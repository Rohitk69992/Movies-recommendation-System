Machine Learning Formulation

Vector Space Model & Recommendation Pipeline

A mathematically rigorous reconstruction of the CampusX content-based recommendation architecture.

01

Multi-Field Metadata Extraction

We extract five discrete content fields from TMDB raw metadata: genres, narrative keywords, top-3 billed cast members, and the film director (isolated via crew.job == 'Director'). Secondary crew roles are omitted to preserve high semantic signal-to-noise ratio.

02

Entity Space Whitespace Collapse

Multi-word entity names undergo whitespace collapse (e.g., "Christopher Nolan" → "ChristopherNolan", "Sam Worthington" → "SamWorthington"). This prevents unigram bag-of-words tokenizers from conflating distinct individuals sharing common first or last names.

03

Tag Synthesis & Morphological Porter Stemming

The consolidated tag string fuses narrative synopsis, entity tokens, and thematic keywords. Tokens are normalized using NLTK's Porter Stemmer algorithm (e.g., "danced" → "danc", "actions" → "action"), collapsing inflectional variants to common morphological roots.

04

Unigram Vectorization & Sparse Matrix Projection

Scikit-Learn's CountVectorizer(max_features=5000, stop_words='english') projects the corpus into a 4,800 × 5,000 feature matrix. The resulting representation exhibits 99.39% sparsity, stored compactly in compressed sparse column format.

05

Pairwise Cosine Metric & Sub-10ms Inference

Similarity between query vector u and candidate vector v is computed via normalized dot product:

cos(u, v) = (u · v) / (||u||2 × ||v||2)

The query movie self-score (cosine = 1.0) is masked, and candidate films are sorted descending. Online inference computes scores against all 4,800 catalog vectors in under 7 milliseconds.
